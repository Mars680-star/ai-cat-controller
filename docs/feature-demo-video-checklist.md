## 1. 建议成片结构

- 主功能演示：6 到 8 分钟。
- 重启持久化验证：单独录制 1 到 2 分钟。
- 异常与安全保护：单独录制约 1 分钟。
- 同时拍到浏览器和 AI 猫；执行动作时保留全身画面，尾巴周围不得有障碍物。
- 不拍摄 API Key、ProductSecret、AccessToken、DeviceSecret 或板端鉴权缓存。

   触摸会被日志标记为 `ignoring touch from unbound device`，不能演示触摸培养。

   “小安小安”本地唤醒。网页动作、状态、音量和培养可以直接拍；完整唤醒词视频
   应在已部署该服务的旧 K1 上拍摄，或先完成新 K1 的唤醒资源部署。

推荐新建演示账号，不要解绑现有测试账号：

1. 点击“退出体验账号”。
2. 使用固定的演示登录码重新登录。
3. 在“连接”页输入 `7c2b63fd4a128`、宠物名称和当前 Wi-Fi 名称。
4. 点击“绑定并开启性格盲盒”。
5. 进入主页，确认性格、亲密度和设备状态已显示。

如需从完全空白状态重拍账号、绑定和性格盲盒，可在“设置”页点击“格式化全部体验
数据”。确认前先结束语音对话；成功后记录页面返回的备份编号并重新登录。该操作会
清除所有体验账号和记录，不会删除火山鉴权、License、SDK 或系统配置。

## 3. 主视频拍摄顺序

### 镜头 1：设备绑定与性格盲盒

操作：

1. 从未绑定状态开始录制。
2. 输入真实序列号并完成绑定。
3. 切换到“主页”。

预期：

- 页面显示设备已绑定、在线和网络名称。
- 首次绑定确定 1 种持久化性格。
- 主页显示宠物名称、性格描述、语言风格、亲密度和当前称呼。

通过标准：刷新页面后宠物和性格不丢失。

### 镜头 2：真实电量和充电器状态

操作：

1. 在“连接”页拍摄实时电量、电池状态、电压和充电器状态。
2. 拔下充电器，等待最多 5 秒。
3. 重新接入充电器，再等待最多 5 秒。
4. 切换到“主页”，拍摄同步后的电量和充电状态。

预期：充电器“已连接/未连接”和充电状态随实机变化，电量不是网页滑块模拟值。

### 镜头 3：7 个安全预设动作

进入“运动”页，每个动作执行完成后再测试下一个，并拍摄网页执行记录：

| 编号 | 网页名称 | 预期真机表现 |
| --- | --- | --- |
| `#001` | 轻轻摇头 | 头部右、左、中，运动平顺且不抽搐 |
| `#002` | 认真点头 | 头部上下点动并回中 |
| `#003` | 开心摇尾 | 尾部左右摆动 |
| `#004` | 骄傲转身 | 头部转向一侧、尾巴摆动、停留后缓慢回中 |
| `#005` | 安静陪伴 | 速度较慢的小幅点头 |
| `#006` | 见面问候 | 点头后摇尾 |
| `#007` | 升级庆祝 | 摇头、点头、摇尾依次执行 |

每次操作后确认：

- 动作期间其他动作不会并发执行。
- 执行记录最终显示完成，而不是一直处于运行中。
- 头部和尾部没有撞击、堵转或持续抖动。

再测试一次“停止当前动作”：启动组合动作后立即点击停止，预期电机停止继续执行，
随后重新执行一个基础动作仍可正常工作。

### 镜头 4：实体触摸、动作和本地短语

操作：

1. 打开“培养”页，先拍摄当前亲密度。
2. 实体触摸猫的头部一次。
3. 等待动作和本地短语播放完成，再等待页面最多 5 秒刷新。
4. 可间隔至少 3 秒后测试鼻部、背部或爪部。

预期：

- 触摸触发固定的点头或摇头动作。
- 播放与性格和触摸部位对应的本地短语，不启动火山云端。
- 每次有效实体触摸亲密度增加 `1`，记录中显示触摸事件。

当前新 K1 为拍摄临时启用了无限触摸计分，培养页应显示“触摸计分不限（调试）”。
正式配置下每日实体触摸最多计分 8 次，并受每日总增长上限约束；拍摄完成后必须
恢复 `AI_CAT_DEBUG_UNLIMITED_TOUCH_INTIMACY=false`。

### 镜头 5：完成任务和亲密度成长

操作：

1. 记录操作前亲密度、等级和升级进度。
2. 点击“完成任务”一次。
3. 拍摄变化后的分数、互动记录、已解锁内容和下一级解锁内容。

预期：完成任务增加 `5`，每天最多计分 2 次；每日所有正向事件合计最多增加 `50`。

### 镜头 6：真机音量和追问时间设置

操作：

1. 在“设置”页把音量改为 `40%` 并保存。
2. 通过一次触摸本地短语或语音回答确认扬声器音量变化。
3. 把音量恢复到拍摄前数值。
4. 将免唤醒追问时间改为 `30` 或 `60` 秒并保存。

预期：页面在最多 5 秒内同步真机 PulseAudio 音量；重新打开页面后设置仍然存在。

### 镜头 7：网页文字提问

仅在火山配置、License 和 `volc-conv-ai.service` 已验证可用时执行：

1. 进入“对话”页。
2. 输入“你现在还有多少电？”并点击“文字提问”。
3. 拍摄状态从连接云端、思考到回答的变化。
4. 等待真机扬声器播报实时电量。

预期：无需说唤醒词，网页按需启动云端；回答结束后，用户问题和 AI 回答出现在同一
会话详情中。空闲超过配置时间后，云端正常断开而不是被永久常驻。

### 镜头 8：本地唤醒和连续语音对话

该镜头只能在已安装并启用 `volc-k1-wake-word.service` 的设备上拍摄。

1. 先拍摄火山服务未连接的状态。
2. 清楚说“小安小安”，等待短提示音或页面进入连接/聆听状态。
3. 问“你现在还有多少电？”。
4. 回答播放完成后，在追问窗口内不说唤醒词，继续问“那你正在充电吗？”。
5. 再问一个普通问题，确认回答内容与当前问题相关。
6. 提出一个会产生较长回答的问题，在回答期间点击“打断并结束”。

预期：

- 唤醒前不连接火山，也不把普通环境对话提交给云端。
- 首次唤醒后自动进入聆听，追问窗口内无需再次说唤醒词。
- 打断后声音立即停止，页面回到结束状态，不延迟播放上一轮回答。

### 镜头 9：对话历史与会话详情

操作：

1. 保持在“对话”页，等待同步完成。
2. 在左侧选择刚才的会话。
3. 展示右侧按时间排列的用户问题和 AI 回答。
4. 刷新页面后再次打开同一会话。

预期：语音问题、文字问题、回答内容和时间均与当前宠物关联，刷新后不会丢失。

### 镜头 10：安全自主动作与本地短语（可选延时镜头）

确认 `toy_motor.service` 为 `active`，云端对话为空闲状态，然后拍摄约 3 分钟延时：

```bash
ssh -i ~/.ssh/codex_k1 root@192.168.1.107 \
  'systemctl is-active toy_motor.service volc-conv-ai.service'
```

预期：按当前性格执行一个已审核的自主头部动作，并可能播放一条预生成本地短语；
该过程不应启动火山服务。若日志显示 `personality_not_ready`，先完成真实设备绑定，
不要把本次跳过录成成功结果。

## 4. 重启持久化视频

重启前拍摄性格、亲密度和最近一条对话。执行：

```bash
ssh -i ~/.ssh/codex_k1 root@192.168.1.107 reboot
```

设备重新联网后刷新网页，预期：

- FastAPI、动作服务和 UI 自动恢复。
- 宠物绑定、性格、亲密度、设置和对话历史保留。
- 火山对话不应在没有唤醒或文字问题时自动常驻连接。

## 5. 不应在本次视频中宣称完成的功能

- 微信小程序和正式微信登录、配网流程。
- 双眼自定义图片切换接口；当前只确认硬件能显示 GIF/PNG。
- RTC、视频上传和厂商 SDK 全部 API。
- 控制台更换音色后对全部 20 个本地 WAV 的完整人工听感验收。
- 多设备并发、长时间压力、全部弱网和断网恢复场景。
