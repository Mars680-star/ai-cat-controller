> 清理真实数据或调整硬件。小程序危险操作仍禁用。本模块不是跨进程锁。

后续阶段增加了可选协作式跨进程层，见[进程维护协议V1](process-maintenance-protocol.md)。
下文记录本模块原始单实例语义；未配置新路径时仍保持该行为。新层也不代表所有

## 解决的问题与覆盖范围

清记忆、解绑或产品库格式化不能只锁自己的数据库事务。例如音量已改、资料尚未
写入，或动作HTTP响应已返回而后台仍在写收尾记录，此时清库会被旧任务随后写回。
`core/operation_gate.py`让一个FastAPI实例的这些完整操作共享维护门。

应用lifespan创建一个`DeviceOperationGate`，注入Product、Motion、Dialog、Device和
Mijia服务；普通构造器仍允许不传门，兼容原有独立用法。Device纯读不占写租约。
进程内自主动作与触摸通过这些服务调用接入，独立原生进程不因此受到约束。

| 入口 | 本地源码行为 |
| --- | --- |
| 产品资料、培养、反馈、原生事件导入和人格同步 | 从校验到数据库/运行文件完成，保留普通操作租约 |
| 音量设置 | 覆盖物理音量、SQLite保存和人格同步，不在两步之间释放 |
| 动作 | 提交与实际后台动作分别保留租约；必须完成的SQLite收尾也单独追踪 |
| 对话配置、文字、聆听、本地播音 | 完整调用受普通门禁保护，不因HTTP断开放弃实际工作 |
| 米家准备/撤销、音量、普通动作及回执 | 普通写入完整受门禁保护；仍只是接入前协议 |
| 清记忆、解绑、全产品库格式化 | 关闭新普通写入、等待已接纳工作收尾，再执行独占阶段 |
| 状态和纯查询 | 无写租约，不排队等待维护；旧历史GET若带导入副作用仍属于普通写 |
| 停止动作、打断对话 | 保留独立安全通道及原权限检查，不被普通写队列卡住 |

## 世代、后台任务与取消

HTTP中间件在读取请求体和解析鉴权之前记录当前世代，不占写租约。维护开始和
结束均推进世代；旧请求即使之前已解析出用户身份，也不能在维护后重新加入写入。
新写入、过期请求和第二个维护请求直接冲突，不等维护结束后自动补发。

普通操作可以嵌套调用。只有同一个实际任务可以直接复用自己的租约；继承上下文
的子任务需要独立登记，不能仅凭继承了一个布尔变量绕过排空。
父操作已经结束的旧上下文不能重新申请普通工作、checkpoint或维护，即使另一
进程的维护没有改变本实例的本地epoch也不行；不能将其刷新成新的跨进程票据。
`spawn`在调度子任务前同步预留租约，父任务返回后仍追踪必要的后台收尾。
已接纳父任务在排空期间仍可登记其必要子任务；普通操作不能升级为维护并等待自己。

HTTP调用方取消只取消等待，不放弃已接纳的写入、磁盘线程或最终回执。可取消的
动作、庆祝等待和触摸播音须实际清理完毕才释放租约；庆祝开始提交动作后，完整的
动作意图/数据库提交另有不可取消租约。可选新动作或声音在等待之后再次检查世代，
不在清理后补播。检查点不能插在一个不可分割写入的物理效果与数据库保存之间。

原生事件监视循环本身不占长期租约、也不继承启动时的旧世代；每轮实际导入重新
加入门禁。这个去上下文机制只供无请求载荷的长期监视器，不供延迟用户写入逃逸。

## 独占阶段与超时

清记忆和解绑先通过`mode=ro`查询确认当前宠物归属，再改变全局门状态；错误用户
或不存在宠物不能使合法请求失效。进入生命周期锁/数据库事务后仍再次核权，预检
不能替代最终校验。格式化仍沿用旧的**全设备产品库**契约和开关，不新增生产管理员。

维护先关闭新写入，再执行必要的静默检查/停止/后台收敛。格式化等待动作收尾不持
人格生命周期锁，排空后再拿锁、重查语音，避免收尾同步与清理互相等待。

默认排空预算5秒。独立计时器在独占实际开始前到期即向调用者返回409；实际开始
前还检查单调时钟的绝对截止时间，防止事件循环卡顿后抢在计时回调之前误执行。
HTTP断开也不能移除这个期限。真实停止清理或磁盘线程可能尚未结束，
不能因为接口超时就强行解锁或谎称工作已完成：若仍在quiesce收敛，门保持关闭直至
其结束；若只是在等普通租约，撤销本次维护并重新开放，旧普通工作继续安全收尾。
已经开始的独占磁盘操作不按该排空预算强行中止。关闭服务时等待已追踪工作。

米家安全停止/打断使用独立锁，不等被卡住的普通命令锁。若物理安全请求已提交，
但维护或旧世代阻止保存回执，固定返回409“停止/打断已请求但维护中未记录回执，
请核对状态”，不误报持久成功，也不在重置后补写旧记录。该响应不等于停止未发生。

## 还不能据此发布的能力

- 仅一个Python实例、一个事件循环；不支持多个ASGI worker协调，不允许同一实例
  跨事件循环复用。原生语音/独立自主进程仍需跨进程维护协议及实际排空证明。
- 全库格式化不等于单宠重置。生产管理员/物理在场授权、范围确认、备份恢复和
  撤权后仅本人可读的独立回执仍待实现，不能把体验会话和开关当作生产权限。
- 小程序清记忆、解绑、重置的真实网关路由及按钮未开放；不通过前端启用绕过缺口。
- 前几阶段原生修复仍需SDK/RISC-V构建、批准后的设备部署与真实音频/动作验收。
- 没有服务器、HTTPS域名或微信发布资质的本地回归不能代表生产上线。

三种数据操作的实际范围、历史保留和备份边界见
[产品数据生命周期](product-data-lifecycle-safety.md)。
