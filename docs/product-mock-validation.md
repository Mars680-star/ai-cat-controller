# 产品 Mock 验证

## 已实现

- Mock 登录、宠物绑定、网络配置、断线与重连状态。
- 宠物主页：名称、性格、等级、电量、充电和网络状态。
- 5 种持久化性格盲盒，解绑和进程重启后保持不变。
- 亲密度规则、等级、每日上限、幂等事件和解锁内容。
- 7 个只读参数的安全预设动作及异步执行记录。
- 性格化文本 Mock、真实火山音色 ID 元数据、对话历史和用户隔离。
- 名称、音量、解绑和异常反馈。
- 浏览器端六模块交互页面，手机窄屏使用底部导航。

## 自动测试覆盖

- 第一阶段设备、服务、动作、对话、鉴权与 Local K1 安全边界。
- 5 个性格配置可查询。
- 用户、设备和宠物 ID 唯一且稳定。
- 已绑定设备不能被其他用户抢占。
- 亲密度重复请求、每日事件次数和每日总增长上限。
- 锁定动作拒绝、动作重复请求幂等和完成状态持久化。
- 离线设备拒绝动作。
- 对话、设置、状态和反馈接口。
- 应用进程重启后恢复性格、亲密度和历史。
- 设备转移后保留性格，但不向新用户暴露旧用户对话。

## 仍是 Mock

- 微信登录、配网协议和小程序代码。
- 云端数据库、设备 TLS 长连接和状态主动推送。
- Mock 模式不调用火山 ASR/LLM/TTS；Local K1 已接入一个智能体内的 5 套动态
  提示词、真实音色和动作规则，5 套音色仍需逐一完成人工听感验收。
- 触摸传感器实测上报；电池管理芯片和充电状态已在 K1 接入。
- 预设动作到 K1 真实电机的安全参数映射。
- 多设备并发、弱网重放、令牌刷新、审计和数据删除策略。

因此本阶段可以验证产品流程与接口契约，不能作为真机完整端到端验收结论。
