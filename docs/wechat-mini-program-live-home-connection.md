## 使用方法

桌面工程仍为 `C:\Users\13691\Desktop\wechat-miniprogram`。重新编译后：

1. 进入“主页”或“连接”，点击醒目的“使用真实设备”。
2. 等本地连接检查完成，点击“微信登录并查看设备”。不会自动登录或认领机器。
3. 点击已授权的“小安”。主页显示真实电量、设备连接与语音摘要；连接页补充
   脱敏编号、电压、电池、充电器和采样时间。
4. 使用底部导航切换这两个页面，前台有效登录与选择保留；新页面重新核对授权，
   再重新采样，不把上一页的旧电量直接作为当前结果。
5. 可手动刷新或下拉刷新，自动采样为前一次结束后等待5秒；没有并发轮询。
   “切回界面预览”恢复原演示。“退出真实设备登录”会尝试撤销服务端会话。

登录，不会把检查页的令牌复制到主页。本轮首次进入新主页须显式登录一次。

## 数据范围

| 界面/字段 | 当前真实接入范围 |
| --- | --- |
| 主页 | 电量、充电状态、设备连接、只读语音状态、采样时间 |
| 连接 | 上述信息＋脱敏编号、电压、电池存在、充电器连接 |
| 性格、亲密度、互动和对话记录 | 尚未迁移真实接口；真实模式不显示演示数值 |
| Wi-Fi名称、设备最后在线 | 当前过滤接口未提供，明确标为未验证，不用演示值填空 |
| 其他六个主入口 | 继续原本地预览，有明确预览标识，不调用真实写接口 |

0%是有效实测值；未知值是“未验证”。设备在线不代表Wi-Fi信号良好；语音服务
离线不代表设备掉线。语音过期或不可用时，不把旧阶段、会话状态或计时当作当前值。
UTC时间是代理本次采样时间，不是设备最后在线时间。

## 会话与流畅度边界

- `services/live-device-session.ts`复用既有8787鉴权client，只有明确切到真实模式
  才检查健康；只有点击登录才调用微信登录，只有点击授权设备才首次采样。
- 首页与连接页共享一个内存闭包；UI、页面data和Storage不接触业务Bearer。
  新的`cancelPending()`可取消请求而保留前台有效身份，`peekSession()`只给到期时间。
- 最后一个真实页面隐藏/卸载时立即取消请求、停止轮询、清快照。切回页面须重新
  读取授权列表。注销、过期、401、退出真实模式或应用切后台会清身份；不落盘续登。
- 整体应用后台还会清空共享会话。清本地内存不是服务端撤销；明确注销若未确认，
  会提示旧会话仍按有效期失效。
- 身份/授权/选择改变与旧请求隔离，旧页面不能回写新页面，错误不回退Mock。
  未变化的共享状态不重复`setData`，预览的旧轮询与晚到加载不会进入真实模式。
- 预览加载不挡住真实入口；即使没有本地演示账号/宠物，也能进入真实主页和连接。
  演示绑定、模拟重连与模拟状态更新在真实模式隐藏，直接调用页面方法也被拒绝。

或重置。后端三路只读过滤、归属和完整身份pin保持上一阶段实现。
