# 网页版与微信小程序功能对齐

> 2026-10-19：当前交付为AI狐狸伴侣0.3纯UI，入口不减少，真实功能未接入。
> 以下操作均为本地演示，导入与验证边界以 `UI-PREVIEW-GUIDE.md` 为准。

## 目标

小程序使用与 `ai-cat-controller` 网页版一致的产品信息架构、字段语义和操作边界，
同时将桌面侧栏改为适合手机的四列两行固定导航。页面不直接读取 Mock，也不直连 K1；
后续只替换 `ApiPetService` 即可接入 HTTPS 网关。

## 导航方案

微信原生 TabBar 最多只能声明 5 项，无法完整承载网页版 8 个入口。本工程不再使用
原生 TabBar，而由 `components/product-nav` 在全部一级页面显示 8 个固定入口，并用
`redirectTo` 替换当前一级页，避免长期浏览造成页面栈增长。二级会话和盲盒仍使用普通
页面导航。

## Service 对齐

页面只调用 `services/pet-service.ts`。当前 `MockPetService` 覆盖所有读写行为；
`ApiPetService` 保留同名方法，后续对接时负责：

- 解开云端 `{success,message,data}` 包裹并转换字段名；
- 注入业务 Session、超时和统一错误；
- 所有写请求复用客户端 `request_id`；
- 将设备、动作、对话、成长、米家和记忆接口映射为页面模型；
- 隐藏 API Key、设备凭据、米家凭据、火山配置和硬件底层参数。

## 数据清理边界

“一键清除记忆”只清除短期原文窗口和长期结构化事实，完整会话继续显示；新对话会
重新形成记忆。“重置全部数据”对应网页版完整格式化流程，清除账号、绑定、性格、
亲密度、记忆、动作、对话和反馈，并返回恢复编号。Mock 使用本地数据模拟该语义。

## 当前验证边界

已经执行 JSON 配置解析、页面事件绑定检查和 TypeScript 检查。最终发布前仍需在
微信开发者工具中检查 iPhone/Android 多尺寸、系统大字号、安全区、长文本和真机点击，
并在正式接口接入后重新验证弱网、超时、幂等重试与登录续期。
