## 本地开发检查（可选）

需要 Node.js 20+，在 WSL 的权威源码目录运行：

```bash
cd /home/kfc/ai-cat-controller/miniprogram
npm ci
npm run build
```

build 生成本地 PNG 图标，并运行源码、TypeScript、本地 Service 与交互生命周期检查。
微信开发者工具仍需人工检查多尺寸、键盘和真机显示，不用这些自动检查替代视觉验收。

完整导入步骤、所有页面映射和场景切换见 [UI 预览说明](docs/UI-PREVIEW-GUIDE.md)。
